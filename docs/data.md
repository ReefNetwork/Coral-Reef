# CoralReef データと保存

## 経験値とスキル

ユーザーインスタンス(UserAccount.php)から取得、変更できます  
ユーザーインスタンスはSQLManager::manager->getUser()で即座に返される ※ユーザーがサーバーにいない場合はnullが返される
(事前に取得されているデータを参照しているだけなのでSQLManagerにあるのはダメだと思う だからあとで場所変えるかも)

### 保存タイミング

プレイヤーが参加して時に取得して抜けた時もしくはデータセーブ時に保存されます

## 土地

サーバー起動時に読み込まれます

### 保存タイミング

土地の情報を変更したとき 変更するのはSQLManagerからどうぞ  
SQLManagerをいじると取得されているデータも変更されます

## その他のデータ

ワープとかガチャ券はその都度データベースから取得する
