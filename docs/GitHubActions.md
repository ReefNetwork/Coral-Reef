# GitHub Actions

GitHub Actionsを用いて自動でビルド、マージ、デプロイを行っています

## 自動ビルド

このリポジトリにプッシュされるよどのブランチでも自動でビルドされます  
自動ビルドを行いたくない場合は
`[ci skip]`
をコミットメッセージに入れてください

## 自動マージ

### Feature

Feature系のブランチでコミットメッセージに
`[feature]`
と入れると自動でmasterブランチへのプルリクエストが作成され、問題がなければ自動でマージされます  
その後デバッグサーバーへデプロイされます

### Stable

masterブランチでplugin.ymlに変更を加えるとstableブランチへ自動でマージされます  
この自動マージを行いたくない場合は
`[merge skip]`
とコミットメッセージに入れてください

## 自動デプロイ

### デバッグサーバー

masterブランチに変更を加えるとデバッグサーバーへ自動でデプロイされます  
また、どのブランチでもコミットメッセージに
`[deploy]`
と入れると自動でデバッグサーバーへデプロイされます

### 本番サーバー

stableブランチへの自動マージ後自動でデプロイされます この自動デプロイを行いたくない場合は
`[deploy skip]`
とコミットメッセージに入れてください
